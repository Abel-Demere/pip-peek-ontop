# PIP Peek On Top 1.0.2

Public Windows x64 helper for PIP Peek Standard-window pinning.

- Dedicated On Top pin icon for the installer and installed helper.
- Branded PIP-Peek-ontop-Setup.exe filename and proper 1.0.2 Windows version metadata.
- Automatic discovery of PIP Peek in standard Chrome profiles; preserves existing allowed extension origins.
- Installs per user without administrator access, a startup service or browser restart.
- Maintains the existing native-messaging identity and installation path for compatibility.
- Runs only for pin checks/changes and validates the PIP Peek Chrome/Chromium window.

Download and run PIP-Peek-ontop-Setup.exe, then return to PIP Peek. It is unsigned.
The extension/player source and extension ZIP are not included in this public release.
SHA256SUMS.txt contains the installer checksum. Source and build instructions are in this repository.
